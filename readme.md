# Sean's Games Collection

Welcome to my collection of small computer games written in Python.

These games were created using Python and tkinter.

## Games

## Wordle

A five-letter word puzzle game.

Features:
- Six attempts to find the hidden word
- Colour clues for correct and incorrect letters
- Statistics tracking
- Guess distribution
- Share results function

Folder:

WORDLE


## Hangman

A traditional word guessing game.

Features:
- Different word categories
- Educational word lists
- Simple child-friendly interface

Folder:

HANGMAN


## About

These games were created as a learning project and are designed to be enjoyed by family and friends.

They are especially intended to encourage children to explore words, spelling and geography.
